# Tamil Nadu Instagram ID Scraping

## 📌 Project Overview

This project focuses on extracting Instagram business IDs and collecting relevant public profile information for businesses in Tamil Nadu.

Instagram business IDs were first extracted category-wise using the Instant Data Scraper Chrome extension. The extracted IDs were then processed using Python and Selenium to collect relevant profile information.

The scraped data was cleaned, organized, and prepared for analysis and Power BI visualization.

## 🎯 Objectives

- Extract Instagram business IDs category-wise
- Collect relevant Instagram profile information
- Automate data collection using Python and Selenium
- Clean and remove duplicate records
- Organize the scraped data in Excel
- Analyze the collected Instagram business data
- Create Power BI dashboards for visualization

## 📸 Instagram ID Extraction

Instagram business IDs were extracted using the Instant Data Scraper Chrome extension.

### Extraction Process

1. Open Google Chrome
2. Open the required Instagram business category page
3. Run the Instant Data Scraper extension
4. Extract the available Instagram business IDs
5. Export the extracted IDs to Excel
6. Prepare the IDs in a new Excel sheet

## 🐍 Python & Selenium Scraping

The extracted Instagram IDs were processed using Python and Selenium.

The scraping workflow was used to collect relevant profile information such as:

- Instagram ID
